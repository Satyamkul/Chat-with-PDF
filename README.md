Chat PDF Agent with Perplexity API 

Overview

This project is a Streamlit-based web application that enables users to upload multiple PDF documents and interactively ask detailed questions about their content using a conversational AI powered by the Perplexity API and LangChain. It combines document processing, vector embeddings, and large language model (LLM) querying to provide accurate, context-aware answers from PDF files.

Features

Upload multiple PDF files at once via a web UI

Extract and chunk textual data from PDFs for efficient retrieval

Use sentence-transformers to create vector embeddings locally

Build a FAISS vector store for fast similarity search

Integrate Perplexity API as a conversational LLM for answering queries

Provide a chat-like Q&A experience over PDF contents

Error handling for missing files, API keys, and empty documents

Tech Stack

Streamlit: Web UI framework for the app

LangChain: Framework for chaining LLMs and retrieval systems

FAISS: Vector similarity search engine for embeddings

Sentence-Transformers: Local semantic embeddings generation

Perplexity API: Large language model for generating answers

PyPDF2: PDF text extraction

Python-dotenv: Managing environment variables

Installation

Clone the repo:

git clone <repository-url>
cd <repo-folder>

Create and activate a Python virtual environment:

python -m venv venv

# Windows

venv\Scripts\activate

# macOS/Linux

source venv/bin/activate

Install dependencies:

pip install -r requirements.txt
requirements.txt should include:

text
streamlit
langchain
langchain-text-splitter
faiss-cpu
pypdf2
python-dotenv
sentence-transformers
requests
pydantic

Create a .env file and add your Perplexity API key:

PPLX_API_KEY=your_perplexity_api_key_here
Usage

Run the app locally:

streamlit run app.py

Upload one or more PDFs via the sidebar

Click "Submit & Process" to extract text, chunk it, and create vectorstore

Ask questions in the input box; responses are generated by Perplexity API using stored embeddings

Code Structure

app.py: Main Streamlit app handling UI, PDF processing, vector indexing, and querying

PerplexityLLM class: LangChain-compatible wrapper to call Perplexity API

Functions for:

Extracting text from PDFs (get_pdf_text)

Splitting text into chunks (get_text_chunks)

Creating/loading FAISS vector store (get_vector_store, load_local)

Building conversational retrieval chain (get_qa_chain)

Handling user queries and UI input/output

Security Notice

The application deserializes FAISS indexes from local pickle files with allow_dangerous_deserialization=True.

Only load indexes you have generated yourself to avoid security risks.

Troubleshooting

Ensure .env contains a valid PPLX_API_KEY

Make sure vectorstore is created before querying

Confirm all dependencies are installed and Python environment is active

Restart environment if env variables are changed
